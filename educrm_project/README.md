# EduCRM — CRM для образовательных центров Кыргызстана

CRM-система для управления образовательными центрами (ОРТ и языковые курсы).
Разработана на Django 4.2 с тёмным веб-интерфейсом на Bootstrap 5.

## Быстрый старт

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Создать и применить миграции
python manage.py makemigrations core
python manage.py migrate

# 3. Загрузить демо-данные (создаст admin/admin123)
python manage.py seed_data

# 4. Запустить сервер
python manage.py runserver
```

Открыть: http://127.0.0.1:8000
Логин: **admin** | Пароль: **admin123**

## Структура системы

| Модуль | Описание |
|--------|----------|
| Дашборд | Метрики, выручка, последние записи |
| Студенты | CRUD + поиск/фильтрация + карточка |
| Группы | Управление группами + наполненность |
| Курсы | ОРТ-курсы и языковые курсы |
| Учителя | Профили + привязка к курсам |
| Посещаемость | Отметка + история |
| Платежи | Учёт оплат + долги |
| Отчёты | Аналитика + источники + должники |

## Модели данных

- **Course** — курс (тип, цена, длительность)
- **Teacher** — учитель (контакты, ставка, курсы)
- **Student** — студент (школа, класс, источник)
- **Group** — группа (расписание, аудитория, учитель)
- **Enrollment** — зачисление студента в группу
- **Attendance** — посещаемость (статус за каждый урок)
- **Payment** — платёж (сумма, способ, статус)

## Переход на PostgreSQL (продакшн)

В `settings.py` замените:
```python
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.postgresql',
        'NAME': 'educrm',
        'USER': 'postgres',
        'PASSWORD': 'your-password',
        'HOST': 'localhost',
        'PORT': '5432',
    }
}
```

## Стек технологий

- **Backend:** Python 3.11 + Django 4.2
- **БД:** SQLite (dev) / PostgreSQL (prod)
- **Frontend:** Bootstrap 5 + IBM Plex Mono + Manrope
- **CSS:** Кастомная тёмная тема с CSS-переменными
- **Деплой:** Gunicorn + Nginx / Railway / Render
